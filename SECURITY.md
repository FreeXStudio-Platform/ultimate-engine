# Security

## Report a vulnerability privately
Use **[Report a vulnerability](https://github.com/FreeXStudio-Platform/ultimate-engine/security/advisories/new)**, or write to
**admin@freexstudio.com** with "SECURITY" in the subject. Please do not open a public issue for a security problem.

Include the version (`ultimate-engine version`), your system, the steps, and what an attacker could do. Never send real
secrets or other people's data.

We aim to acknowledge a report within seven days and to tell you what we will do. Please give us time to release a fix
before you publish details. We do not currently offer a bounty.

## Supported versions
Only the newest release receives fixes. Automatic updates keep installations on it.

## Releases and updates
Releases are signed off the hosting service; installed copies install only releases that verify against the key they
carry. How to check a download yourself: [docs/VERIFY.md](docs/VERIFY.md).

## What the software's checks do not do
They reduce the risk of some mistakes. They do not prove a document or a system is secure or safe to publish.
