- Implementation discoveries recorded for future upgrades:
  - zrender emits global counters (`zr<N>-`, `cls/gradient/clip-<N>`) that break build-twice determinism across `init()` calls in one process → normalized by first-appearance renumbering in `render.mjs`.
  - Quoted font-family names (`"Inter", …`) reach an SVG `font` attribute unescaped in ECharts 6.1.0 SSR output → invalid XML for strict parsers (resvg). Theme uses unquoted family lists.
  - `echarts.init(null, THEME_NAME, …)` is required for registered themes to apply in SSR — passing null renders the default theme silently (caught by the reskin regression test).
