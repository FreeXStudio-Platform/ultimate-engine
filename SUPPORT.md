# Help and support

| You want to | Go to |
|---|---|
| Report something broken | [Bug report](https://github.com/FreeXStudio-Platform/ultimate-engine/issues/new?template=bug_report.yml) |
| Ask for a feature, a chart or a change | [Feature request](https://github.com/FreeXStudio-Platform/ultimate-engine/issues/new?template=feature_request.yml) |
| Ask how to do something, or share an idea | [Discussions](https://github.com/FreeXStudio-Platform/ultimate-engine/discussions) |
| Report a security problem | [Privately](SECURITY.md) |
| Ask about licensing or commercial use | admin@freexstudio.com |

We read every report. This version is free, and no response time or fix is promised.

**Before you post:** everything here is public. Remove names, addresses, paths with your user name, keys, tokens and
private document content from text, logs and screenshots.

## Why you cannot send code
The source is not published and we do not accept pull requests. Tell us what you need; we make the change.
